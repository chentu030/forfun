# 古籍內化講義：共用規格

## 讀者與目標
讀者是一位中文（繁體）讀者，起點是 `handouts/_reader_goal.txt`：一份關於「腦內過度模擬、耗神、收神聚氣」的筆記。
他想要的不是學術考證，而是**真正讀懂原典，並把它內化成自己日常可用的心法與做法**。
講義要讓他：
1. 知道這本書在講什麼、為什麼值得讀、該讀哪些篇。
2. 讀懂精選原文（逐段：原文 → 字詞註 → 白話 → 這段在說什麼）。
3. 把思想連回他的主題（止念、不將不迎、事上磨鍊、養神、氣機），並有具體可做的練習。
4. 讀完能自我檢驗：反思題、一頁總結、常見誤解。

語氣：清楚、溫和、像一位好老師，不玄虛、不說教。可以提到「玄學解析」那份筆記的觀點，但要誠實區分**原典本意**和**後人或現代的引申**；若筆記中的說法與原文不符或引文出處有誤，要溫和指出。

## 素材
- 原文：`books/<書名>.txt`（中文維基文庫，公有領域）。章節以 `==== 標題 ====` 分隔。檔案裡可能夾雜少量導覽雜訊（如 `←`），引用時去掉。
- **引用原文只從這個檔案取**，逐字照抄，並標出篇名。
- 白話翻譯、字詞註解、導讀、解說、練習：**全部由你自己寫**。
- **不可**複製或改寫任何現代譯本、注本、講義、網路文章的文字（例如陳鼓應、南懷瑾、傅佩榮、曾仕強等人的作品）。可以在「延伸閱讀」中列出書名推薦，但不引用其內容。古代注家（如郭象、王弼、朱熹、陶弘景）的注語是公有領域，可以少量引用並標明出處。

## 版面與輸出
- 每份講義是一個獨立 HTML 檔，放在 `handouts/<書名>/`，檔名如 `01-內篇精讀.html`，同名輸出 `.pdf`。
- 一本書出一份或多份 PDF，由你依內容決定。每份大約 15–40 頁 A4 為宜；太長就拆。
- HTML 開頭固定：
  ```html
  <!doctype html><html lang="zh-Hant"><head><meta charset="utf-8">
  <title>…</title><link rel="stylesheet" href="../handout.css"></head><body>
  ```
- 可用的樣式（定義在 `handouts/handout.css`，不要改這個檔；需要少量額外樣式就寫在 HTML 的 `<style>` 裡）：
  - 封面：`<section class="cover"><div class="series">古籍內化講義</div><h1>書名</h1><div class="subtitle">副標</div><div class="meta">…</div></section>`
  - 目錄：`<section class="toc"><h2>目錄</h2><ol>…</ol></section>`
  - 章節：`<h2>`、`<h3>`、`<p>`、`<ul>`/`<ol>`、`<table>`
  - 原文：`<div class="yuanwen">原文……<span class="src">〈篇名〉</span></div>`
  - 白話：`<div class="baihua">…</div>`
  - 字詞註：`<dl class="notes"><dt>字詞</dt><dd>解釋</dd>…</dl>`
  - 提示框：`<div class="box"><span class="label">重點</span>…</div>`；變體 `box apply`（練習 / 實作）、`box reflect`（反思題）、`box warn`（常見誤解）
  - 換頁：`<div class="pagebreak"></div>`
- 轉 PDF：`sh /tmp/claude-0/-home-user-forfun/62b650a1-069c-5d72-a073-1ac82f67c009/scratchpad/kit/render.sh 輸入.html 輸出.pdf`
- 檢查：用 `pdfinfo` 看頁數；用 `pdftoppm -r 50 -png -f N -l N 檔.pdf 前綴` 轉幾頁成圖片，用 Read 工具看圖，確認中文正常、版面沒有破掉、原文框沒被切壞。有問題就修。

## 每份講義建議結構（可依書調整）
1. 封面、目錄
2. 導讀：這本書是什麼、作者與時代、核心思想一頁看懂、跟讀者主題的關係、閱讀路線
3. 精讀：選最關鍵的篇章段落，逐段「原文 → 字詞註 → 白話 → 解說」，穿插「重點」框
4. 內化：把思想轉成具體練習（每日、遇事時、睡前等），寫清楚做法
5. 常見誤解
6. 反思題
7. 一頁總結（可以撕下來貼牆的那種）
8. 延伸閱讀（只列書名與一句話理由）

## 限制
- 只在 `handouts/<你負責的書名>/` 底下建立或修改檔案。不要動其他資料夾，不要 git commit 或 push。
- 完成後回報：產出的檔案清單、各 PDF 頁數、每份講義涵蓋的篇章、任何你覺得讀者該知道的事（例如筆記裡哪個引文出處不正確）。
